# Sentinel SOC API

## Descripción
API para la gestión de vulnerabilidades, alertas del IDS, bloqueos en tiempo real y sesiones.

## Instalación y Ejecución
1. Instala las dependencias:
   `pip install fastapi uvicorn`
2. Ejecuta el servidor:
   `uvicorn app.main:app --reload`
3. Consulta la documentación interactiva en: `http://127.0.0.1:8000/docs`
